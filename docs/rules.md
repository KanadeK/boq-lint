# BOQLint v0.1.0 规则说明

本文描述 BOQLint / 清单体检 `v0.1.0` 的行识别、数值读取、稳定规则编号、默认严重程度和修复建议。规则用于通用数据质量辅助检查，不是标准条文复刻或合规认证。

## 严重程度

| 级别           | 含义                                               |
| -------------- | -------------------------------------------------- |
| 错误 `error`   | 数据缺失、无法可靠读取或计算明显不一致，应优先处理 |
| 警告 `warning` | 值得人工复核，但可能存在合理业务场景               |
| 提示 `info`    | 结构或计算能力限制，需要用户确认                   |

页面和报告始终同时显示图标/文字与颜色，不仅依赖颜色表达状态。

## 模式与必需字段

| 内部字段       | 中文     | 未计价模式     | 已计价模式           |
| -------------- | -------- | -------------- | -------------------- |
| `item_code`    | 项目编码 | 必需           | 必需                 |
| `item_name`    | 项目名称 | 必需           | 必需                 |
| `item_feature` | 项目特征 | 空值警告       | 空值警告             |
| `unit`         | 计量单位 | 必需           | 必需                 |
| `quantity`     | 工程量   | 必需且检查数值 | 必需且检查数值       |
| `unit_price`   | 综合单价 | 不要求         | 必需且检查数值       |
| `total_price`  | 合价     | 不要求         | 必需且检查数值和计算 |

`serial_no`（序号）和 `remarks`（备注）不是必需字段。“编号”只默认映射为序号，不默认映射为项目编码。

## 表头与行识别

BOQLint 在每张工作表的前 30 行中按同义词评分寻找表头，并允许用户手动选择表头行和字段映射。表头归一化处理首尾空格、换行、连续空白、中英文冒号、全角形式和大小写差异。

检查前会区分：

- **明细行**：进入字段、数值、重复、单位、计算和结构规则。
- **章节标题行**：不作为普通明细产生必填误报。
- **小计/合计行**：不作为普通明细产生必填或计算误报。
- **重复表头行**：由 `STRUCT-003` 提示，并从明细规则中排除。
- **完全空白行**：忽略。

行分类是可解释的启发式处理，目的是降低误报，不表示工具理解完整工程语义。用户仍需确认表头和字段映射。

## 数值读取

有效数值形式包括：

- Excel 数值单元格；
- `1234.56`；
- `1,234.56`；
- 数字前后空格；
- 括号负数，如 `(12.50)`；
- 带有可读取缓存结果的公式单元格。

BOQLint 不从任意混合文本中强行提取数字。`12m`、`约 10`、`待定` 等内容不是有效数值。金额计算使用 `decimal.js`，不直接依赖 JavaScript 二进制浮点数。

## 规则清单

### REQ-001 必需字段缺失

- **默认级别**：错误
- **触发**：明细行缺少当前模式要求的任一字段。
- **记录**：缺失字段、工作表和 Excel 行号；同一行可有多个字段问题。
- **修复建议**：确认字段映射；如映射正确，在原工作簿补充必需内容。
- **配置**：核心规则，不可关闭。

### NUM-001 无效数值

- **默认级别**：错误
- **触发**：当前模式要求读取的工程量、综合单价或合价缺失，或不是上述有效数值形式。
- **降噪**：公式错误和公式无缓存会由公式规则说明；不得把任意含数字文本强转为数值。
- **修复建议**：清理文本字符，使用数值单元格；公式应在 Excel/WPS 中重新计算并保存。
- **配置**：核心规则，不可关闭。

### QTY-001 工程量非正

- **默认级别**：警告
- **触发**：有效工程量等于零或小于零。
- **说明**：负数可能用于调整、冲减等场景，因此不是致命错误。
- **修复建议**：结合业务场景确认数值和备注；无依据时在原工作簿修正。

### DUP-001 完全重复明细

- **默认级别**：警告
- **范围**：同一工作表内。
- **触发**：两条或更多明细行的映射字段内容完全相同。
- **记录**：关联 Excel 行号。
- **修复建议**：确认是否为分区/分层的有意拆分；否则删除或修正重复项。

### DUP-002 同编码内容冲突

- **默认级别**：警告
- **范围**：同一工作表内的非空项目编码。
- **触发**：同一项目编码对应不同项目名称、计量单位或项目特征。
- **修复建议**：逐行核对编码、名称、单位和特征；确认是编码错误还是业务允许的拆分。

### UNIT-001 计量单位冲突

- **默认级别**：警告
- **触发**：同一项目编码，或同一标准化项目名称，出现不同计量单位。
- **说明**：名称相同不一定表示计量口径相同，本规则只提示复核。
- **修复建议**：确认名称是否应区分、单位是否录错，以及字段映射是否正确。

### CALC-001 合价计算不一致

- **默认级别**：错误
- **适用**：已计价模式，且工程量、综合单价、合价均为有效数值。
- **计算**：使用 `decimal.js` 计算 `工程量 × 综合单价`，按两位小数比较。
- **默认绝对允许误差**：`0.01` 元。
- **触发**：表内合价与计算合价的绝对差额超过允许误差。
- **记录**：表内合价、计算合价、差额和当前容差。
- **修复建议**：核对三个数值、公式、舍入口径和缓存结果；在原工作簿修正。

### FORMULA-001 公式结果错误

- **默认级别**：错误
- **触发**：映射字段的公式缓存结果为 Excel 错误，例如 `#REF!`、`#VALUE!`、`#DIV/0!`、`#N/A`、`#NAME?`、`#NUM!` 或 `#NULL!`。
- **修复建议**：在 Excel/WPS 中检查引用和公式逻辑，重新计算并保存后再次检查。

### FORMULA-002 公式无可读取缓存

- **默认级别**：提示
- **触发**：单元格存在公式，但文件中没有浏览器可读取的缓存结果。
- **说明**：这表示 BOQLint 无法确认结果，不表示金额一定错误；不得据此触发确定的计算结论。
- **修复建议**：使用 Excel/WPS 完整重新计算并保存，再重新导入。

### TEXT-001 项目特征为空

- **默认级别**：警告
- **触发**：明细行的项目特征为空或只含空白。
- **修复建议**：结合图纸、合同和计量要求补充影响计量与组价的必要特征。

### CODE-001 项目编码格式空白风险

- **默认级别**：警告
- **触发**：项目编码存在首尾空格、换行或明显的全角字符。
- **说明**：BOQLint 只提出规范化建议，不自动修改，也不判断所有地区编码规则。
- **修复建议**：在原工作簿清理不可见空白或确认全角字符是否为录入错误。

### STRUCT-001 关键字段跨合并单元格

- **默认级别**：警告
- **触发**：明细数据的关键映射字段受合并单元格影响。
- **修复建议**：取消明细区合并，或将每条明细整理为独立行后重新检查。

### STRUCT-002 隐藏明细或关键列

- **默认级别**：提示
- **触发**：工作表存在隐藏的明细行或关键字段列。
- **修复建议**：取消隐藏并复核内容，或确认隐藏设置确有业务依据。

### STRUCT-003 明细区域重复表头

- **默认级别**：提示
- **触发**：首个表头之后的明细区域再次出现可识别的表头。
- **处理**：该行不进入普通明细规则，避免产生大量缺失或数值误报。
- **修复建议**：如无分页/打印需要，可删除重复表头；否则保留并确认后续明细映射一致。

## 规则配置

- 用户可以启用/禁用非核心规则、修改 `CALC-001` 允许误差、查看说明并恢复默认设置。
- `REQ-001` 和 `NUM-001` 在适用模式下不可关闭。
- 配置可导出为 JSON，也可导入；导入前必须验证版本、字段、类型、规则编号和数值范围。
- 未知字段、未知规则、负容差、错误类型或缺少必要结构的配置会被拒绝，并显示可理解的原因。
- 只把规则配置保存到 `localStorage`；工作簿内容、文件名、映射结果和检查问题不持久化。

## 结果解释

“未发现问题”只表示所选工作表、当前字段映射、检查模式、规则开关和容差下没有命中规则。它不表示无漏项、价格合理、定额正确、编码符合所有地区要求，或成果符合任何标准。

产品工作场景可参考住房城乡建设部的[《建设工程工程量清单计价标准》公告](https://www.mohurd.gov.cn/gongkai/zc/wjk/art/2024/art_6186304e164c4c4982904f8734983235.html)。本文不复制标准表格或编码库，也不替代正式标准文本。

**BOQLint 是通用数据质量辅助工具，不构成工程造价专业意见，也不代表检查结果符合任何国家、行业或地方标准。正式成果文件仍需由具备相应资格的专业人员复核。**
