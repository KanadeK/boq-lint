# 领域假设与专业边界

BOQ Lint（清单校核）面向工程量清单 Excel 的数据质量与一致性辅助检查。它能发现值得复核的结构、字段、数值和重复风险，但不能仅凭一份电子表格得出完整的工程造价审核结论。

## 为什么无法只凭 Excel 判断真正漏项

“漏项”意味着本应根据图纸、合同、招标范围、技术规范、施工组织、现场条件或计量规则列入的工作内容没有被列入。单独一份工程量清单 Excel 通常不包含判断这些责任边界所需的全部证据。

例如，同一条未出现在清单中的工作内容，可能是：

- 确实遗漏；
- 已包含在另一清单项的项目特征或综合单价中；
- 属于措施项目、其他项目或总价措施范围；
- 由甲供、暂估、专业分包或合同界面承担；
- 在图纸、合同或补充协议中明确排除；
- 使用了不同的拆分、归并或计量口径。

因此，BOQ Lint 可以提示“表内字段缺失”“疑似重复”或“结构异常”，但不会声称自动发现真正漏项。漏项判断必须联合图纸、合同、招标范围、计量规则和专业人员复核。

## 为什么编码格式只能提示

常见工程量清单项目编码可能采用 12 位数字，但地区、行业、补充项目、企业模板和不同阶段成果可能存在其他编码方式。编码还可能包含前缀、后缀、分隔符或内部管理编号。

`QG006` 只把“去除空格后不是常见 12 位数字格式”作为提示，不直接认定违规。复核人员需要结合项目适用的规则、地区要求和企业模板确认编码是否合理。

`QG005` 对项目编码缺失也只给出警告。补充项目、临时汇总表或企业内部模板可能允许空编码，工具不能脱离上下文武断处理。

## 为什么负单价和零单价可能有业务含义

综合单价小于零或等于零值得复核，但并不一定是错误。可能的业务背景包括：

- 赠送项或合同约定不单独计价；
- 抵扣、冲减、返还或调整项；
- 暂不计价、待定价或由其他费用覆盖；
- 反向调差或历史数据迁移；
- 企业模板中的占位值。

因此，`QG011` 的严重程度为 warning。工具提示核对数值、合同依据和备注，不自动将其提升为确定错误，也不自动修改原工作簿。

## 为什么同名项目单价差异只作为风险提示

相同或相近项目名称与计量单位并不保证可直接比较。综合单价可能因以下因素合理不同：

- 项目特征、材质、规格、施工位置或工艺不同；
- 工程量规模、运输距离、施工条件或时间不同；
- 风险、税费、暂估、甲供和合同口径不同；
- 分区、楼层、标段或供应条件不同；
- 名称相同但特征描述不完整。

`QG012` 只有在同一规范化名称与单位至少存在 4 项时才计算中位数，并在偏差超过用户阈值时给出 info。它是筛选复核对象的统计提示，不是市场价格判断、限价结论或错价认定。

## 与 GB/T 50500-2024 的边界

BOQ Lint 的产品设计参考现行工程量清单工作流程以及 GB/T 50500-2024 所处的业务环境，但：

- 不复制或内置标准正文、表格、完整编码库或受版权保护内容；
- 不宣称“完全符合 GB/T 50500-2024”；
- 不对成果进行标准符合性认证；
- 不解释标准条文的法律或合同效力；
- 不替代注册造价工程师、招标人、咨询人或其他专业人员审核；
- 不替代图纸、合同、计量规则、地区规定和正式标准文本。

文档中的全部 QG 规则都是“辅助检查规则”。规则命中表示存在需要复核的数据风险，不等于违法、违规、漏项、错价或审核不通过。

## 数据与知识产权边界

项目只包含完全虚构、由脚本生成的示例。贡献者不得提交：

- 真实工程量清单、客户或企业资料；
- 商业计价软件的真实导出样本；
- 非公开价格、投标或合同数据；
- 受限制的定额库、价格库或标准全文；
- API Key、Token、密码或个人隐私信息。

> BOQ Lint 仅用于工程量清单 Excel 数据质量辅助检查，不构成造价审核结论，也不能替代图纸、合同、计量规则及专业人员复核。
